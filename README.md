# Maderóh WEB

Página web oficial de Maderóh.

## Arquitectura

Frontend:
- HTML
- CSS
- JavaScript

Backend:
- Netlify Functions

Base de datos:
- PostgreSQL

Hosting:
- Netlify

Repositorio:
- GitHub

## Páginas

1. Inicio
2. Productos
3. Personaliza / Proyectos

El contacto por WhatsApp está disponible durante toda la navegación.

## Seguridad

Las credenciales privadas nunca deben almacenarse en frontend.

El archivo `.env` no debe subirse al repositorio.

Las variables privadas de producción deben configurarse mediante las variables de entorno de Netlify.

## Desarrollo local

Instalar dependencias:

npm install

Ejecutar:

npm run dev
